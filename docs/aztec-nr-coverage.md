# aztec-nr v6.0.0 failure modes and total_aztec coverage

One row per failure mode: what fails, who can cause it, and which
total_aztec entry covers it. "Owner" is the owner of the state or of the
called contract; "caller" is a contract or argument supplier; "sender" is
the transaction's own user and PXE. A "Yes" means the operation no longer
fails; it does not mean a third party can read the value (note reads find
nothing without the owner's keys).

| Area | Operation | Fails when | Caused by | Covered |
|---|---|---|---|---|
| Notes | PrivateImmutable / SinglePrivateImmutable get_note | No active note in the reader's PXE ("Failed to get a note", Brillig trap): never initialised, not delivered, or owner's keys absent | Owner, caller (names an owner), sender | No trap: `storage.x.get_note_or(owner)`, single_private_immutable_get_note_or. A third party without the owner's keys always gets found = false |
| Notes | PrivateMutable / SinglePrivateMutable get_note, replace, initialize_or_replace | Missing note as above; every read nullifies, which needs the owner's nullifier key (key oracle errors in any other PXE); initialize_or_replace branches on a possibly stale hint | Owner, non-owner caller (always), sender, owner's other device | Partly: `get_note_or` reads without nullifying (inclusion only, value may be stale); replace and the nullifying read not covered |
| Notes | PrivateSet get_notes | Code indexes an empty result; argument-driven reads exceed 16 read requests; hint breaks a select, sort or limit | Owner (no notes), caller (arguments), sender | Partly: `storage.x.get_notes_or::<N>(owner)`, get_notes_or (per-note flags; no selects, sorts, filter, offset; sums are not balances) |
| Notes | PrivateSet pop_notes, remove | Nullifying needs the owner's key (non-owner PXE errors once a note is returned); over 16 nullifiers per call | Non-owner caller, sender | Partly: consume_with_nullification_proof_or, one note with the owner's proof passed as an argument with the leaf's witness (determined; a non-verifying proof under passing flags fails proving, chosen by whoever passes the handoff) |
| Notes | Initialise a PrivateImmutable / PrivateMutable / Single* | Already initialised (duplicate nullifier: kernel, or dropped at insertion); needs the owner's key (the contract's for Single*) | Owner, owner's other device, sender | No |
| Notes | Create notes (insert, create_note) | Over 16 note hashes or 16 logs per call from argument-driven loops; an undelivered note message loses the note silently | Caller (arguments), sender | No |
| Notes | Read a slot holding another note shape | The note hash has no type id, so the PXE serves every note the class committed at the slot. aztec-nr's get_notes: a wider note makes the oracle refuse the return; a narrower one shifts the metadata (a one-Field-narrower note owned by the contract at storage slot 3 matched and named a note hash that does not exist); a non-canonical integer member truncates to a note hash nobody committed; a bool member outside {0,1} asserts in unpack | Class code (the contract's author), including notes it creates on purpose | Yes for get_note_or / get_notes_or, except one state: the hint fetches each note's raw packing with MAX_NOTE_PACKED_LEN spare Fields and drops every note without the exact layout of the reader's width (stage 1, 2 or 3 as a Field, nonce consistent with the stage and never 0 to 3 for a nonced stage, zero tail, canonical packing; a misaligned note passes only if its kernel nonce is 1, probability 1/p, and then reads as pending), a settled note unless the PXE holds a settled note with the reader's note hash and nonce (get_settled_note_origin), and a pending note unless this call pushed the reader's note hash. The circuit finds a note only if the note hash it computes once, and names in the read request, equals the one the hint checked and, for a pending note, is one this call pushed, so a hand-written NoteHash, a raw notify_created_note, one slot read with two types, a note hash that differs between Brillig and ACIR, and the misaligned residual read as found = false (note.nr, "The note hash the read request names"; TXE tests in noir/total_aztec_driver). A pending note created by another call of the transaction is not found either. Not closed: a pending note wider than MAX_NOTE_PACKED_LEN plus the reader's width (a note type outside #[note]) makes the PXE refuse the read; total-lint reports every notifyCreatedNote call that creates one (note-width). A bool member's assert in unpack is reported by total-lint as an abort site of the reader |
| Notes | Note getter hint checks | Oracle returns another contract's, owner's or slot's note, out of order, or over the limit | Sender (its PXE) | Yes for get_note_or / get_notes_or: the contract, owner and slot checks are flag terms |
| Notes | Note-hash read request | Note not in the tree at the anchor block (created later), or a pending read of a note not yet emitted: kernel rejects after a successful simulation; over 16 per call or 64 per transaction | Sender (anchor), network (timing), callee sharing the budget | Partly: get_settled_note_from_witness_or checks the caller's witness against the anchor root with a flag before it pushes the read request (determined, no oracle); note_hash_exists_at_anchor (flag from the caller's witness, no oracle, no kernel request, determined); every note read flags a note past the call's 16 read requests as not found, and emits a pending read request only for a note hash the call pushed before it; the 64 per transaction are shared and kernel-checked |
| Notes | SingleUseClaim claim, assert_claimed, has_claimed | Owner's key needed; second claim is a duplicate nullifier; assert_claimed asserts a hint, then a nullifier read request | Owner, owner's other device, non-owner caller | Partly: nullifier_exists_at_anchor for a computable nullifier; the claim nullifier needs the owner's key |
| Notes | Partial note completion | Empty, over-length, mismatched or duplicate completion log: the partial note is marked completed and lost; no transaction fails | Whoever completes the note | No |
| Notes | Utility reads (view_note, view_notes, is_initialized, has_claimed, msg_sender) | Caller's PXE only: missing note traps, owner's key needed, view limit above 10, no msg_sender | Sender, caller | No |
| Public from private | PublicImmutable read | Not initialised at the anchor: hint assert ("Trying to read from uninitialized PublicImmutable"), nullifier read request; a hint not matching the stored hash; class code that writes the value or hash slots directly (raw public storage writes) so the stored hash does not match the stored value | Owner (never or later initialised), sender, class code (raw writes) | Yes: public_immutable_read_or proves every slot at the anchor (no hint, no kernel request) and reads a missing, mismatching or non-canonical stored value as ok = false, determined; public_immutable_is_initialized. This contract's own storage only. T must have no bool member (a directly written 2 with a matching hash asserts in unpack; total-lint reports it) |
| Public from private | PublicMutable read | No private read exists; the value can change before inclusion | Owner | No |
| Public from private | DelayedPublicMutable get_current_value | Lowers the expiration to the time horizon (at most the delay, minimum 1 h, less the anchor's age; a pending change - 1 s); dropped if not included by then. Its hint check asserts the hinted packing against the stored hash, which class code writing its slots directly can break | Owner (delay, pending changes), network, class code (raw writes) | Partly: delayed_public_mutable_read_or proves every slot at the anchor and reads a stored state the variable's own functions cannot write (hash mismatch, values with a zero hash, a non-canonical packing, a delay below 1 h, where aztec-nr's horizon subtracts 1 from 0) as ok = false, determined; on ok it lowers the expiration as aztec-nr does. aztec-nr's get_current_value is not usable in a total function (total-lint reports its hint check). No bool members in T. Not covered: the expiration itself; with direct writes the class can schedule a change one second after each block, leaving readers an expiration at their anchor |
| Public from private | public_storage_historical_read | Total for every slot (unwritten reads 0); fails only if the PXE cannot serve the witness | Sender, network | No |
| Public in public | PublicImmutable initialize, read | Already initialised (duplicate nullifier) or read before initialisation: public reverts (included with fee paid, dropped in setup) | Caller, racing initialiser, owner | No |
| Public in public | DelayedPublicMutable scheduling | Delay below 1 h; timestamp or delay at or above 2^32 fails the pack (a delay near 2^32 bricks scheduling); provable reverts | Owner, caller | No |
| Initialisation | Private init check (functions without #[noinitcheck]) | Contract not initialised by the anchor: unsatisfiable nullifier read request, also for a callee's own check | Owner (never initialised), caller (calls it) | Yes: contract_is_initialized + #[noinitcheck] (anchor-relative; callee applies it to itself; always false without an initializer) |
| Initialisation | Initializer arguments after the initializer, in the same transaction | The initializer's effects (its notes, its nullifier at the anchor) are not readable by a later call | The protocol | Yes: initializer_args_or (a hint the initializer records with record_initializer_args, checked against the initialization hash in the address: flag bound; plus the anchor-relative initialisation flag). Not covered: class code that writes an element wider than one Field at the hint's transient slot, with the raw transient oracles, makes the read abort |
| Initialisation | Private #[initializer] | Init hash mismatch, wrong deployer, the transaction's first call whatever the deployer (the deployer check evaluates maybe_msg_sender().unwrap() even when the deployer is zero; TXE test in noir/total_aztec_driver), already initialised (dropped) | Caller, racing initialiser, sender | No |
| Initialisation | Public init check, public #[initializer] | "Not initialized" revert (including calls enqueued before the initializer's own), public init nullifier emitted twice; provable reverts | Caller, another transaction, owner | No |
| Macros | #[only_self], #[view], #[authorize_once], msg_sender() | Wrong caller, non-static call, or first call with no msg_sender (unwrap); msg_sender() under enqueue_incognito in public | Caller | No |
| Macros | Phase guard | Body or a callee calls end_setup without #[allow_phase_change] | Callee's owner, caller | No |
| Private context | Push a nullifier | Duplicate in the tree or the transaction: not checked by the private kernel, the base rollup drops the proven transaction (no fee) | Owner (other device), any racing transaction, sender | Partly: nullifier_exists_at_anchor and consume's spent flag check the anchor; a spend after the anchor still drops |
| Private context | Per-call limits | 16 note hashes, nullifiers, logs, each read request kind, key validations; 8 nested calls, 32 enqueued calls, 8 L2-to-L1 messages, 1 class log ("push out of bounds") | Sender's code, caller (loop arguments) | Partly: get_notes_or static-asserts N <= 16; note reads and the nullification-proof consume flag a full request or nullifier vector instead of pushing past it |
| Private context | Per-transaction limits and gas | 64 note hashes, 63 nullifiers, 64 logs, 64 per read kind and key validations, 16 private calls, 32 enqueued, 8 messages (unprovable); gas above the wallet's limits | Callee's owner (shared budgets), sender | No |
| Private context | Key validation (request_nhk_app) | PXE holds no key for the account (oracle error), so only the owner can nullify, initialise or claim; over 16 keys per call | Non-owner caller (any `.at(other)`), sender | Partly: `get_note_or` needs no key; consume_with_nullification_proof_or replaces it for one note; registered_npk_app_hash and set_key_or are owner-only, carry no lint marker, and are reported unless the call site justifies them |
| Private context | Emit a private log or event | Over 16 per call or 64 per transaction; non-zero fields past the length; a note log for a note hash not emitted earlier | Sender's code, caller, callee's owner | No |
| Private context | L2-to-L1 message | Ninth message; recipient above 160 bits | Sender, callee's owner | No |
| Private context | Consume an L1-to-L2 message | Not in the tree at the anchor, wrong content/secret/sender/index, or consumed first by another transaction | Caller, anyone with the secret, network | No |
| Private context | Expiration | Below the including block's timestamp (anchor over 24 h old, past timestamp, slow inclusion): proven transaction dropped | Sender (anchor), network, any called contract's owner (DelayedPublicMutable reads, upgrades) | No |
| Private context | Older block header (get_block_header_at) | Block at or after the anchor, header or archive witness unavailable | Caller, sender, network | No |
| Calls | Private call | Callee fails for any reason (its asserts, limits, init check, oracle errors); unknown contract or selector | Callee's owner (code), caller (address, arguments) | No |
| Calls | Callee's class | Nothing lets the caller's circuit pin or flag the class it audited; the owner can upgrade it | Callee's owner | No |
| Calls | Return value (get_preimage) | Return does not match the expected arity ("Preimage mismatch" or a hint length error): another class at the address, or an upgrade | Callee's owner | Partly: static_call_flagged_or reads any M + 1 Fields and flags the last; another arity still fails, so total-lint reports the call unless the call site justifies its target |
| Calls | Static call | Callee emits a note hash, nullifier, log or message, elects a fee payer, ends setup or sets a teardown: kernel rejects | Callee's owner | No |
| Calls | Callee changes transaction-wide state | Lowers the expiration, ends setup, elects a second fee payer or teardown, exhausts shared budgets | Callee's owner | No |
| Calls | Enqueue a public call or teardown | Reverts at inclusion (dropped in setup; included as reverted with fee in app logic); calldata missing from the cache or a 33rd enqueue fails simulation | Public callee's owner, another transaction, caller, network (timestamp and block checks) | No |
| Calls | Public function internals | Unknown selector, re-thrown callee revert, return shape mismatch, write under static call, out of gas; provable reverts | Caller, callee's owner | No |
| Account | Entrypoint (AccountActions::entrypoint) | Signature flag false (one assert, intended); no auth witness ("Unknown auth witness"); reused cancellation nonce (dropped); fee payer after setup | Sender (account owner), same account's other transaction | Partly: the signature check is a total flag asserted once (examples/total_account); the oracle error and nonce are not flagged |
| Account | Entrypoint in the account's own deployment transaction (self-paid deployment: the constructor, then the entrypoint) | The key note the constructor just created is a pending note of another call, which no flagged read can find, so a note-based signature check is false | The protocol (only the kernel checks another call's note hashes) | Yes in examples/total_account: until the initialisation nullifier is in the anchor block's tree the check takes the constructor's key, recorded by the constructor and checked against the address (record_initializer_args, initializer_args_or); afterwards the key note. The executor chooses the anchor, so the constructor's key authorises transactions anchored before the deployment, included up to MAX_TX_LIFETIME (one day) after their anchor |
| Account | Private authwit check | On-behalf-of account unregistered, its check asserts, has no witness, returns another selector or emits; duplicate authwit nullifier; no msg_sender at the first call | Owner (on-behalf-of account), caller, caller's own retry | No |
| Account | Public authwit check | Registry consume reverts (not authorised, revoked before inclusion; provable, fee paid); registry absent | Owner, another transaction, network | No |
| Account | Fee payment | No or two fee payers; balance too low, base fee above the maximum, or a fee contract's setup revert at inclusion: dropped | Sender or paymaster, another transaction (shared payer), network, callee's owner | No |
| Keys | get_public_keys | Address unknown to the PXE; hint that does not derive the address or has an off-curve ivpk_m | Caller (address), owner (never shared its address), sender | No |
| Keys | Use a stored Grumpkin key | Off-curve or infinity point stops witness generation ("is not on curve"), bricking every reader; an on-curve key in a known relation to bb's MSM offset generators (one of them, say) has no proof when it reaches the MSM black box unblinded | Owner | Yes: key_ok, decode_key_or on read; refuse_bad_key (an assert, for the writer's own transaction; the call site must justify it) and set_key_or (owner-side, ok = false unless owner is msg_sender) on write; the decoded key used through total::ec::msm_or or total::schnorr_verify has a proof for every on-curve value |
| Messages | Encrypt and deliver a note or event | Encryption never fails (invalid recipient encrypts to a random point); constrained tagging panics for an invalid recipient; handshake registry unregistered or failing; interactive handshake needs the recipient | Caller (recipient), owner (recipient), network (registry) | No |
| Messages | Constrained delivery sequence | Predecessor send dropped: its nullifier read request fails after simulation; parallel sends reuse an index (duplicate nullifier) | Sender's other transactions | No |
| Messages | Delivery prerequisites | No sender for tags, a tagging strategy that cannot back constrained delivery, randomness giving a bad ephemeral key | Sender (wallet) | No |
| Sync | Callee sync before every private call (sync_state, process_message, offchain_receive) | The caller's PXE runs the callee's sync for the caller's scope before each private call into it, outside every function body: a broken handshake-registry read, an off-curve ephemeral key in a registered handshake (traps the MSM), an implausible offchain anchor or out-of-scope recipient abort the caller's simulation; malformed ciphertexts are skipped | Another account (handshakes, offchain messages), network | No: blocks every private call into the victim, total contracts included |
| History | assert_note_existed_by | Leaf not in the tree at the block (oracle error), wrong witness; settled notes only | Caller (leaf, block), sender, network | Partly: note_hash_exists_at_anchor (flag at the anchor from the caller's witness, determined, no oracle) |
| History | Nullifier history (existed, did not exist, note nullification) | Leaf or low leaf unavailable, wrong witness; note history needs the owner's key | Caller, sender, owner (key) | Partly: nullifier_exists_at_anchor (determined, anchor only) |
| History | Publication and initialisation proofs | Same nullifier proofs; wrong init hash proves nothing useful | Caller, sender | Partly: contract_is_initialized, nullifier_exists_at_anchor (anchor only) |
| Instances | get_contract_instance, publish | Instance unknown ("No contract instance found"), forged instance, deployer-bound instance from another address | Caller, sender | No |
| Instances | Upgrade of a called contract | Kernel reads the updated class at the anchor: old-class proof unprovable after the switch; before it, expiration capped at the switch (default delay 24 h; the callee's owner can lower it to 10 minutes, a change itself delayed) | Callee's owner | No |
| Capsules | load, store, CapsuleArray | A scope that is neither one of the transaction's accounts nor the zero address throws; read past a CapsuleArray's length or a missing element; another contract's store; a missing slot loads as none; a capsule the contract's own code stored earlier is read in place of a staged one; the PXE returns a stored capsule at its stored length, so one of another length stops the reader ("Foreign call return value does not match expected size") | Sender, caller (a scope taken from msg_sender), class code (stores at any slot of its contract) | No: not usable in a total function (nothing commits to the contents and the read can abort). total_aztec reads no capsule; the nullification-proof handoff is an argument |
| Simulation vs proving | Separate executions | Hint-backed flags (a note read's found) can differ between simulation and proving; PXE writes made during a simulation (capsule deletes, note state) are committed | Sender (wallet flow) | Partly: the determined entries (witness reads, nullifier and public-state reads, the nullification-proof consume) give the same flags in both; note reads' found is the prover's choice |
| Oracles | PXE prerequisites | Oracle version mismatch, artifact unregistered, preimage missing from the execution cache, AVM opcode outside public | Sender (toolchain, wallet) | No |
| Conversions | Typed unpack and deserialise | Integer casts truncate (no failure, but a re-hashed note no longer matches); bool outside {0,1} asserts; byte decoders range-check (248 bits, chunk below the modulus); out-of-range discriminants | Caller (own arguments), owner or class code where raw fields reach storage or notes | Partly: note reads drop a non-canonical note packing (re-pack check in the hint); a bool member's assert in the hint is reported by total-lint; KeyNote's Field-only pattern avoids both; arguments and public storage not covered |
| Transaction | Anchor and protocol constants | Anchor no longer in the archive (reorg), or chain id, version, vk tree root or protocol-contracts hash changed before inclusion: dropped | Network | No |
| Transaction | First call and protocol nullifier | First call cannot be static and has no msg_sender; reused salt replays the protocol nullifier (dropped) | Sender (wallet) | No |
